# SQLAnalyst documentation

SQLAnalyst turns plain-English business questions into safe, read-only SQL,
runs them against your databases and answers with a table, a chart and a short
explanation.

| Guide | What it covers |
|---|---|
| [Getting started](setup.md) | Install and run the backend and frontend on Windows, macOS or Linux, or with Docker |
| [Configuration](configuration.md) | Every environment variable for the backend and frontend |
| [Architecture](architecture.md) | How the pieces fit together and what happens when a question is asked |
| [Databases & data sources](data-sources.md) | The default database, adding databases from the admin panel, and choosing one in the chat |
| [Security](security.md) | Login, sessions, the 11-check SQL safety engine, rate limits and a production checklist |
| [API reference](api.md) | Every HTTP endpoint, who may call it, and example requests |
| [Development & testing](development.md) | Project layout, running the tests, coding conventions and troubleshooting |

New here? Start with [Getting started](setup.md), then read
[Databases & data sources](data-sources.md).
